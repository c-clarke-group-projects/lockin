# User guide

Status: stub. Written in week 6, WBS 6.2.1, backlog PB-32, owner   .

Target reader: a teacher or a study group organiser running their first quiz with nobody
from the team in the room. Plain language, short steps, 1 screenshot per step where a
screenshot helps.

The guide must cover these 5 things, which is the acceptance criterion on PB-32.

## 1. Upload your material

Create an account, upload a text based PDF, choose how many questions to generate between
5 and 30, and read the list of pages that could not be used.

## 2. Review the questions

Check each question against the page and snippet it came from. Edit the wording, delete a
question, or regenerate a single one. Add your own questions by hand or import a CSV with
the template. Save the quiz.

## 3. Start a room

Open a saved quiz, create a room, and show the big screen. Participants join with the 6
digit code, the link or the QR, using a display name only. Watch the lobby fill, then
start.

## 4. Run the quiz

How the timer works, how scoring works, how to move to the next question, what participants
see on their phones, what to do if someone loses their connection, and how to deal with a
question the room flags.

## 5. Read the gap report

Final rankings, results per question, and the pages the room got wrong most often. How to
use the flagged question list to fix the quiz before running it again.
